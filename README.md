# logF-core_service

Scaffolding base de arquitectura NestJS para LogFood Core Service.

## Scripts

- `npm run lint`: validación TypeScript (`tsc --noEmit`)
- `npm run build`: compilación TypeScript a `dist/`

## Estado actual

- Arquitectura base creada con enfoque modular monolith.
- Estructura de módulos y capas preparada para Clean Architecture/DDD/SOLID.
- Sin lógica de negocio, sin endpoints funcionales, sin integraciones externas.
